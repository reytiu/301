Lesson: Understanding Sets

A Set is a collection of distinct objects. In mathematics, we use sets to group numbers, variables, or even physical items.

1. Basic Notation

  • Element (∈): An object that belongs to a set.
  • Empty Set (∅): A set with no elements.
  • Subset (⊆): When all elements of Set A are also in Set B.
